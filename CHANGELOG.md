# Historial de cambios

## 1.0.0 — 2026-08-30

- Se preservaron los datos, códigos y resultados científicos originales.
- Se añadió una capa portable de auditoría, percentiles y pruebas automáticas.
- Se identificaron y excluyeron de la publicación dos figuras legadas vacías.
- Se separó la reproducción legada de la sensibilidad sin recentrado futuro.
- Se añadió una puerta de calidad que evita llamar P90 financiero a resultados académicos.
- Se fijaron 136 solicitudes ERA5-Land y 215 fuentes CMIP6 en manifiestos públicos.
- Se excluyeron datos crudos, archivos grandes y figuras redundantes sin borrarlos localmente.
- Se añadió una reproducción rápida desde tablas y una reconstrucción completa protegida.
- Se preparó README profesional, CI y guía clic por clic para GitHub.
